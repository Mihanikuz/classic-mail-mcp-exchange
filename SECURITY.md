# Security policy

The latest public 2.x release is supported with fixes. This is a public preview, not an independently audited product.

Please report vulnerabilities using [GitHub private vulnerability reporting](https://github.com/kapitelh/classic-mail-mcp/security/advisories/new). Do not open a public issue containing exploit details, credentials, email content or callback URLs.

Include the affected version, deployment mode, a minimal synthetic reproduction and likely impact. Never test against somebody else's mailbox or deployment. If private reporting is unavailable, open an issue asking for a private contact without disclosing the vulnerability.

See [the security model](docs/security.md) for trust boundaries and limitations. Rotate exposed credentials immediately and preserve relevant logs privately.
